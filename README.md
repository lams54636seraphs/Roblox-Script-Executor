## FAQ

### What is XCutors?

XCutors is a curated pack that bundles several popular Roblox script executors — Volt, Synapse Z, Potassium, and Wave — along with a universal loader (xcutorsLoader) for convenient management on Windows.

### What does xcutorsLoader do?

xcutorsLoader is a universal loader that lets you install, manage, launch, and update all included executors from a single, unified interface.

### What are Roblox executors?

Roblox executors are Windows desktop tools that allow users to run custom Lua scripts within Roblox games for UI modifications, automation, and personal gameplay customization.

### What are the system requirements?

XCutors requires Windows 10 or later (64-bit), at least 4 GB of RAM, and a stable internet connection for downloading updates and script dependencies.

### Is XCutors free to use?

Yes, XCutors and xcutorsLoader are free to download. Individual executors included in the pack may have their own licensing terms set by their original developers.

### How do I update the executors?

xcutorsLoader includes a built-in auto-update feature. You can also manually check for updates from the loader dashboard at any time.

### Can I add my own scripts to the script hub?

Yes. Navigate to the script hub directory within the loader, create a new category folder if needed, and place your .lua files there. They will appear automatically in the hub.

### Why do some executors require disabling anticomponent software?

Certain executors use memory manipulation techniques that may trigger false positives in anticomponent software. You can whitelist the executor folders to resolve this.

### Where can I find Lua scripts to use with XCutors?

XCutors includes a built-in script hub. Additionally, community scripts can be found on dedicated Roblox scripting forums and GitHub repositories.

### How do I report bugs or request features?

Please open an issue on the GitHub repository with a detailed description of the bug or feature request, including your OS version and executor used.
